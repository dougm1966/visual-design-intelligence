# Nine-design showcase

These nine HTML prototypes represent **nine distinct, fictional business types and visual languages**.

Open `00-start-here.html` in a browser for an overview or open individual `01`–`09` HTML files. They contain no backend and should not be treated as deployed business websites. Their interactive components are demonstrations using fictional local state.

See [desktop comparison](../images/nine-desktop-comparison.jpg) and [phone comparison](../images/nine-phone-comparison.jpg).

The demos were produced in an isolated pilot to test visual diversity; skill performance will vary by agent and brief.
