# Contributing

Thanks for helping make Visual Design Intelligence more effective and more diverse.

## Good contributions

- New **original** visual style recipes with distinct layout, typography, and interaction principles.
- Improvements to accessible patterns, responsive behavior, design briefs, and QA guidance.
- Reproducible test cases that reveal repetition or usability problems.
- Documentation and test improvements.

## Before proposing changes

1. Keep the skill framework-neutral and project-independent.
2. Do not include third-party screenshots, code, text, assets, or fonts without verifiable redistribution rights and attribution.
3. Do not include client data, credentials, production URLs, or personal information in example briefs or demos.
4. Run `python scripts/style_catalog.py validate` and `python scripts/validate_package.py`.
5. Describe the design problem solved, changes made, actual verification performed, and limitations.

Prefer small focused pull requests. Changes that expand this skill into production deployment or website administration belong in a separate project.

Contributors agree that their submitted contributions may be distributed under the repository's MIT License.
